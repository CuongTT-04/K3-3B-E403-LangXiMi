## 3. Việc phải làm
1. **Xoay model:** env `GEMINI_MODELS` (danh sách phẩy; mặc định `gemini-3.5-flash,gemini-3.6-flash,gemini-3.5-flash-lite,gemini-3.7-flash,gemini-3.8-flash,gemini-3.1-flash-lite`); nếu có `GEMINI_MODEL` thì đưa lên đầu danh sách (bỏ trùng). `GeminiLLM.generate` thử từng model theo thứ tự: 429 / 404 / 503 / timeout ⇒ chuyển model kế NGAY (không retry cùng model, trừ timeout 1 lần); 200 nhưng JSON hỏng ⇒ thử model kế; hết danh sách ⇒ `MockLLM` như cũ. Ghi `logger.warning` mỗi lần chuyển. Model dùng thành công lần trước được ưu tiên thử trước ở lần gọi sau (cache thứ tự trong instance). Parse: chọn `parts` có key `text`. Xong khi: test monkeypatch `httpx.Client.post` trả 429 cho model 1, 503 cho model 2, 200 cho model 3 ⇒ kết quả parse từ model 3 và `instance.last_model == "<model 3>"`; test tất cả 429 ⇒ trả dict shape Mock, không raise.
2. **Cache đĩa:** `backend/.runtime/llm-cache.json` (dict, đọc lazy, ghi sau mỗi lần gọi thật thành công; thư mục đã gitignored). Cache hit ⇒ không gọi mạng, trả bản sao dict. `LLM_CACHE=off` tắt; env `LLM_CACHE_PATH` ghi đè đường dẫn (test dùng `tmp_path`). Chỉ cache kết quả THẬT từ Gemini, KHÔNG cache kết quả rơi về mock. Xong khi: test gọi 2 lần cùng input với `post` được đếm ⇒ `post` chỉ gọi 1 lần; test `LLM_CACHE=off` ⇒ gọi 2 lần.
3. **Đếm provider:** biến module `llm.STATS = {"gemini": 0, "cache": 0, "mock_fallback": 0}` tăng đúng nhánh; `llm.reset_stats()`. KHÔNG thêm field vào schema. Xong khi: test sau 1 lần thật + 1 lần cache ⇒ `STATS == {"gemini":1,"cache":1,"mock_fallback":0}`.
